# 2026-10-08 试玩反馈修订

本版针对上一轮试玩发现的问题，不代表完整退役生涯已开发完成。内容仍以童年培养至首个国际青年赛季为主。

- 教练会预判疲劳并安排恢复；休息实际降低负荷，旧疼痛记忆不再永久压制成长。受伤或主动高负荷训练仍有风险。
- 成长路线同样预判恢复；赛季快捷推进会更新已接受的教练课程，而不是永久重复旧周数。手动修改的训练表仍保留玩家安排。
- 跳跃区分尝试、训练基础与比赛就绪；高周跳解锁后，已学过的低周跳仍可编排。新 3A 不借用 2A 的稳定性。
- 国内赛事可一次选择本季报名，取消查看不推进时间；已报名比赛到期直接进入赛前流程。没有可用国际报名或派遣路径的赛事在后台进行。
- 首次教学赛延至初期准备之后；保留旧存档已产生的邀请，不强行重置。
- 旋转与步法按共享基础、动作特征及现场执行定级，不把低级动作自动视作失误。
- 转播依据实际动作与裁判协议显示基础分、GOE 和无效符号；技术栏移到冰场旁，减少轨迹遮挡。
- P 分取消跳跃基础分乘数，区分滑行表演基础、当场失误和长期优质表现积累。高难度不自动带来高 P 分。

旧存档不会补造已经发生的训练成功、比赛分数或名次。新逻辑从之后的训练与比赛生效。升级前请从旧页面下载存档备份；若新版本没有列出旧存档，可导入 JSON 后再读取，不要先清理网站数据。

旧存档若还没有新版本的教练课程记录，请先通过“与教练商量”确认一次训练方向；之后赛季快捷推进会据此更新课程。系统不会猜测旧训练表是玩家手动安排还是教练建议，以免覆盖你的自定义计划。

当前画面仍是抽象冰痕与选手标记，不是人物动作动画。本轮已检查本机实际渲染和 Web 构建、存储桥接静态检查；当前环境未完成真实浏览器交互复验，不将其称为全浏览器验收。

验收：1052 项常规检查、6 项完整赛季检查和两条从 2014 年开档至首个国际青年赛季结束的公开路线均通过，合计 1060 项，最终日志无断言或运行时错误。曾出现的长路线失败及测试脚本问题保留在本地验收记录中，修正后分别重跑。一个测试样本在国内逐步取得竞争力，两站 JGP 最终为第 15、16 名；这是样本结果，不代表整体玩家的成功率。
