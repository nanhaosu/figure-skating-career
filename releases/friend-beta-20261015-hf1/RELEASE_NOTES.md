# 2026年10月15日赛季规划窗口修补版（hf1）

[进入修补版](https://nanhaosu.github.io/figure-skating-career/releases/friend-beta-20261015-hf1/index.html)

## 修复范围

赛季节目与专项规划的确认按钮原先被固定窗口裁切，关闭窗口后再次训练会返回未确认的规划，造成无法继续。现在规划正文可内部滚动，确认操作固定在可见页脚。叉号仍只关闭窗口；确认本季方案才提交选择。没有改变训练、评分、派遣规则或存档版本。

旧生涯可以继续，不需要重新开档。请先在旧页面导出JSON备份，再关闭旧页面并进入修补版；不要清除网站数据。存档版本仍为19，旧发布目录保留。

## 已验证与未完成

本次修改后完整监督回归1257项通过、零失败、无未处理运行错误，运行器三个自检通过，实际退出码0。定向53项通过；实际浏览器已验证2017规划关闭、重开、确认、训练、刷新及恢复。最终导出安装真实IndexedDB保存确认桥并通过资源与防缺项检查。

这是技术阻断修补，不是好玩验收。用户已转述五名测试者对休赛期活动的负面反馈，逐人原始问卷和设备信息尚未核实。休赛期、训练目标呈现、U系列漏通知、国际赛重复确认及派遣问题仍待整改，本版不宣称修好。新摘要完整平衡样本和独立性能验收也尚未完成；旧摘要28个历史样本不算作本版完成样本。
