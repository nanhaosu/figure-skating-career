# 花样滑冰生涯 · 生涯升级测试版

版本：career-beta-20261113。面向花滑爱好者的桌面浏览器测试版，仍在开发中。

## 这次可以体验什么

- 赛季目标与竞争形势：查看目标赛事、资格缺口、规则、截止日和减赛影响。
- JGP 第二站派遣、国内竞争与候补，以及跨季协会名额和成年 GP、奥运周期相关流程。缺少完整官方选拔依据的地方明确标为游戏政策。
- 三三、阿克塞尔、节目表现三种备战方向：展示实际课程变化，保留五种普通三周跳和恢复训练。训练目标不会直接变成已掌握能力。
- 节目升级与比赛规则检查：显示改编前后的基础分、熟悉度和负荷代价；学习到新跳跃后仍须编排、练习并锁定节目。
- 代表作档案、节目回顾及冰场舞台的早期体验。
- 修复跨赛季对手规定单跳与连跳重复、过期报名打断推进，以及训练界面的待处理决定检查顺序等问题。
- 修复临时训练方案到期后不能正常重新安排训练，以及伤病训练被拒绝前仍迁移日期并自动保存的问题。

## 赛历与玩法边界

2014 至 2021–22 的生涯与北京周期，加上后续赛季已核实赛事的逐场接入。2022–23 页面仍会出现明确标注的架空测试赛事；这不是完整复刻至 2026–27 的正式赛历。档案参考、配额计算、可实际参赛是不同完成程度，请以游戏内状态为准。

部分旧赛事的精确日期或晋级名单仍待核实，会保留待核查记录，不为它们生成未经证实的成绩。

备战方向已用真实生涯存档验证。单个存档的不同训练路线可能取得相同比赛分数：本版不承诺所有方向都已形成理想的难度与收益平衡。三三和 3A 是继续发展的目标，五种普通三周跳只是基础要求。

## 存档先备份

浏览器存档保存在本机；清除网站数据、无痕模式结束或更换设备可能丢失进度。请在“存档管理”中选择档位，使用“下载／导出”定期备份，再通过“上传／导入”恢复。

同一网站下的新旧版本可能共用浏览器存储。打开本版前请导出旧档；旧版本不保证能读取新版本写入的存档。旧版链接保留，但回退网页不等于自动回退存档。

切换版本前请等当前保存完成并关闭原版本页面，避免在两个版本中同时推进同一存档。

首次打开需要下载游戏资源。当前主要验收桌面 Chromium / Edge；手机、小屏触控和其他浏览器尚未完成验收。建议使用至少 960×720 的窗口。

已知显示问题：外部自动保存完成后，存档管理偶尔保留上一轮写入提示；档位时间、下载与实际存档仍可正常更新。遇到疑问可先下载备份，再刷新确认。

长生涯存档的导入、保存和部分后台比赛结算仍较慢，后续将继续优化档案体积与写入流程；本版不宣称这些慢节点已经全部解决。

问题反馈请附版本、浏览器、出错前最后一步和可复现的导出存档；不要公开包含个人信息的文件。
